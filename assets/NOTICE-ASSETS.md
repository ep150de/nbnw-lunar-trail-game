# Asset provenance

## Short version

Every pixel and every note in this repository is **original, generated from
source code in `tools/`, or CC0**. Nothing here is traced, ripped, sampled, or
sourced from a game asset pack. No NASA imagery is included.

## Art

All artwork is generated by `tools/gen_art.py` from ASCII-art sprite definitions
and procedural terrain code, and is committed as PNG. It is therefore
**CC0 1.0 Universal** by the same argument as the code: it was produced from
instructions that are in this repository.

- `assets/sprites/*.png` — generated by `tools/gen_art.py`
- `assets/gen/font5x7_preview.png` — generated by `tools/gen_font.py`
- `assets/gen/font5x7.h` — generated by `tools/gen_font.py`

To change the art, edit `tools/gen_art.py` and re-run it. The pixel data is
diff-able in git because its source is text.

## Font

`assets/gen/font5x7.h` is a hand-authored 5x7 bitmap font. Each glyph is defined
as ASCII art in `tools/gen_font.py`. It is original work and is released under
CC0 1.0 Universal.

The 5x7 grid is the same form as the character generator ROMs the Apple II
Oregon Trail used, but no glyph data was copied from Apple, MECC, or any
reimplementation. All 111 glyphs were drawn from scratch for this project.

## Audio

`assets/sfx/` is **empty**. No sound files are bundled.

The game loads CC0 audio if you place files there, and runs silently otherwise --
see the table in `src/core/audio.cpp` for the filenames it looks for. This was
deliberate: shipping someone else's samples would mean taking on their licence,
and no CC0 set was available that matched the aesthetic. The result is a silent
game rather than a licensed one.

To add sound, drop CC0 files in `assets/sfx/` named `click`, `select`, `deny`,
`beep`, `alarm`, `sol`, `impact`, `power`, `radio`, `wreck` (`.ogg` or `.wav`),
and document them below.

## NASA imagery

**None is included in this repository.**

NASA material was consulted as an external design reference only -- specifically
the Lunar South Pole Visualizations gallery and the LROC/SVS imagery of Shackleton
crater, used to choose the palette's regolith ramp and to place the permanently
shadowed regions relative to the sunlit rim.

It is worth being precise about why it is excluded rather than merely unattributed.
NASA content is **not CC0 and not a public-domain dedication**. It is generally
uncopyrightable in the United States as a work of the U.S. government
(17 U.S.C. §105), which is a different thing: it carries no licence grant, only
usage guidelines. NASA requires acknowledgement, prohibits implying endorsement,
and the insignia, logotype and mission patches are restricted by 14 CFR Part 1221
regardless of copyright. Some material hosted on NASA sites is third-party
copyrighted, which NASA's own use does not convey to anyone else.

Committing none of it means this repository can say, truthfully and without
hedging, that every asset in it is CC0. A downstream user inherits a clean chain
of title. That is worth more than the convenience of shipping a couple of
photographs, and the game needed only a palette and a sense of where the shadows
fall.
